# Expeditors International of Washington

> Expeditors International of Washington is a Fortune 500 global logistics company — air and ocean freight forwarding, customs brokerage and trade compliance, order management, warehousing and distribution — operating a company-owned branch network. Its one publicly documented API is the Expeditors Tracking API (v2), a read-only REST/JSON service that lets a contracted customer pull shipment, container, order-management container and consignment tracking data, events, trace references and document images into its own systems.

This file is generated by API Evangelist from the provider's public developer surface. It is not published by Expeditors.

- [Expeditors Tracking API](https://help.expeditors.com/globalhelp/shipment_api/home.htm): Read-only shipment, container, OM container and consignment tracking. ## Authentication

- Token endpoint: `POST https://api.expeditors.com/tracking/v2/oauth2/token`
- Client authentication: HTTP Basic, Base64 of `clientId:clientSecret`
- Grant: `client_credentials` only; scope `application`; token type `bearer`; `expires_in` 900 seconds in the documented example
- Resource calls: `Authorization: Bearer {token}`
- Credentials are issued by an Expeditors representative — there is no self-service sign-up

## Limits and conventions

- Default rate limit 2,000 requests per clock hour; token endpoint 10 requests per hour; exhaustion returns HTTP 429 `too_many_requests` until the next hour begins
- No RateLimit-*/Retry-After response headers are documented
- Pagination is `sizeLimit` (1–100000, default 1000) and `offset` (0–100000, default 0); responses are bare JSON arrays with no total or next link
- All timestamps are UTC in `YYYY-MM-DDThh:mm:ssTZD`
- Data window: active shipments plus those completed in the last 120 days
- Read-only surface: every resource operation is a GET, so there is no idempotency, dry-run or reversal contract
